# README Maintainer

1. Read repository structure, package manifests, scripts, compose/config files, and relevant docs.
2. Preserve valid sections and update stale information.
3. Do not invent commands, ports, requirements, environment variables, or architecture.
4. Prefer copyable commands and minimal examples.
5. Use `TODO:` when critical information is missing.
6. Link to detailed docs instead of duplicating them.
7. Use `references/readme-template.md` when creating a new README.
